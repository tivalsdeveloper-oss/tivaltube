# TivalTube 0.1.0

Initial public release of TivalTube.

- Download individual videos with selectable quality.
- Extract MP3, M4A, Opus, WAV, or FLAC audio.
- Download playlists and subtitles.
- Inspect metadata without downloading media.
- Use the Python API or the `tivaltube` terminal command.
